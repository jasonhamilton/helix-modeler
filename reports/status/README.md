## Helix Native engine

**Status:** working · **Health:** partial · **Completion:** ███████░░░ 72% · **Evidence:** unit-tests, **hardware**

**Purpose.** Render a DI clip through a candidate preset offline in Helix Native, fast enough to be the searching engine.

**Done when.** A NativeEngine behind the frozen interface renders any chain structure the search needs at a measured cost, loads candidates without a GUI step per candidate, agrees with the Stomp within a measured null residual, and has run a full synthetic recovery pass.

**Why 72%.** Hands-off loading (file drop plus MIDI-CC map), state-based reset renders (0.28 s, bit-identical to dedicated captures at -317 dB, flat 3.0 GB), stale-template protection and a memory watchdog are built, hardware-measured on one Mac, and exercised by a 449-render real-song search. Block-serial rendering is shown to equal one instance above 20 Hz (-67 to -79 dB). Still missing: Windows and Linux (the drop route is macOS VST3 only), stereo and dual-cab paths in the host, a block-bypass CC encoding Native honours, the single-block library, and any full synthetic recovery pass. Quality of what Native renders versus the pedal is only partly in parity (see evaluation), and nothing it renders has been blind-tested by ear.

**Tasks.** 8 of 10 done: T002, T012, T013, T018n, T026, T043, T044, T045, T047, T048  
**Owners.** native-engine, benchmark

**Functionality today (partial).** Loads an arbitrary generated .hlx into Native with no human (in-process file drop, about 66 s per new chain structure, once per machine; needs TONEMATCH_NATIVE_AUTOCAPTURE=1 and a logged-in GUI session), drives parameters through a MIDI-CC map, and renders a 2 s clip in about 0.28 s with memory flat near 3.0 GB. Renders are history-independent and match each file's own capture at -317 dB. Mono in and out only; chains with an enabled delay or reverb need a 3 s pre-roll; Windows and Linux are untested.

### Challenges and findings

- Host memory grew 4 to 11 GB and was killed: pedalboard treats Native as keeping audio on reset, so every reset render re-created the plugin and Native never freed an instance (+353 MB each). Fixed by resetting by state; renders are now 0.28 s instead of about 2 s and bit-identical to dedicated captures. Scores from runs before 2026-10-15T18:54 are not exactly reproducible (history-dependent at -62 to -72 dB). _[DECISIONS 2026-10-15 native-engine host memory; ledger 2026-10-15T18:54:10]_
- The old and new reset paths disagree on randomly set parameters (levels 11.6 to 14.4 dB apart). The new path matches each file's own drop capture, so it is believed correct, but this is not independently confirmed. _[DECISIONS 2026-10-15 native-engine host memory (open question)]_
- A stale template was reused for a second file with the same chain structure but a different unmapped parameter, which produced a false parity row (voided). Templates are now keyed by structure plus a hash of baked values and legacy templates are refused. _[DECISIONS 2026-10-15 stale Native template; ledger/void.csv]_
- Native's reset does not clear delay lines: a chain with an enabled delay alternates between two renders (-19.7 dB) at the default 0.1 s pre-roll; 3 s fixes it (-62 to -65 dB). _[ledger 2026-10-15T00:16:00+00:00]_
- Block-serial: the -22.6 dB untrimmed result is an artefact of each instance's 16-sample delay against modulation; trimming 16 samples per instance gives -67.1 dB above 20 Hz, but the full band is limited to -50 dB by sub-5 Hz content from the delay. An Amp+Cab block is not exactly an amp block followed by a cab block (0.021 dB, -72.7 dB gain-matched). An unexplained -67 dB floor appears once the amp follows other blocks. Dual cab, stereo paths and non-default settings are not tested. _[DECISIONS 2026-10-15 T045; ledger 2026-10-15T19:21:10 blockserial-v0]_
- Native applies a drop-loaded file's block values and ignores its stale snapshot values (-330.1 dB versus -38.3 dB); capture now syncs snapshots to blocks. A block-bypass MIDI-CC encoding Native honours has not been found, so bypass patterns need one capture each. _[ledger 2026-10-15T19:42:45; DECISIONS 2026-10-14 T018n stage 2]_
- Whole-preset state write is impossible (opaque encrypted records); the file drop is the supported route. The human clicked 'Change HC mode' once and ticked 'Don't ask again' to get a clean start state; no state edits were adopted. _[docs/notes/native-spike.md; DECISIONS 2026-10-14 human rulings]_
- The Native installer EULA is silent on training ML on Native renders; the human marked the EULA reading done but recorded no finding. _[docs/notes/line6-eula-flags.md; DECISIONS 2026-10-14 project licence]_
